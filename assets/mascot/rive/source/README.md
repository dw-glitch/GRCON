# Fonte raster oficial do mascote GRCON

O arquivo `grcon-mascot-official-default.png` é um recorte exato de 314 × 314 px da primeira célula (canto superior esquerdo) do arquivo oficial `grcon-mascot-sprite.png`, preservado na raiz do repositório.

Os arquivos `body`, `head` e `right-arm` são camadas mutuamente exclusivas obtidas apenas por máscara/recorte desse PNG. A recomposição das três camadas possui diferença de zero pixels em relação ao recorte oficial. Nenhuma parte foi desenhada ou gerada novamente.
